# Kid Timekeep

Kid Timekeep is an Android app of visual countdown timers for children. A child sees time running out as a shrinking hourglass with an emoji picture instead of reading numbers, and a parent sets up and controls the timers. The app is available in English and Latvian.

Screenshots are in [docs/qa/](docs/qa/).
